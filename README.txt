HOW TO PUBLISH
1. Add your CV PDF to this folder, named exactly: Pravalika_Ananthula_CV.pdf
2. Upload this whole folder to a GitHub repository, then connect it to Netlify (or drag the folder onto app.netlify.com/drop).

HOW TO EDIT
All text is in index.html. Search for the words you want to change and replace them.
Photos are in the images folder; replace a file with one of the same name to swap a photo.
